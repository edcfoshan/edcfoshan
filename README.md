## 🔧 我在做什么

- **桌面工具**：Tauri v2 + 纯 Rust 原生开发，绿色便携、离线可用；ArcGIS Pro Add-In（DAML / C#）
- **数据管道**：Python + ArcPy / GDAL，SHP · FileGDB · 界址点 TXT 的读写与互转
- **坐标投影**：CGCS2000 · 西安 80 · 北京 54 · WGS84，高斯-克吕格 3°/6° 分带
- **正在探索**：AI Agent × GIS —— 让大模型直接读懂并操作地理数据
